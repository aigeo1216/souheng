# P3.1 微信咨询集成

## 已实现的可复用能力

- `WechatConsultModal`：全局单例弹层；支持 CTA、悬浮入口和咨询页触发，支持遮罩、Esc 关闭与焦点返回。
- `OfficialAccountQr`：用于 Footer、关于页、知识文章页末尾的公众号二维码组件。
- `useWechatConsult`：集中维护弹层状态、触发位置和服务类型，避免同页重复初始化。
- `useAnalytics`：统一事件数据结构并派发本地 `souheng:analytics` 浏览器事件；未配置统计服务时不声明或模拟成功上报。

事件名称：`cta_click`、`wechat_consult_open`、`wechat_qr_view`、`wechat_qr_save`、`official_account_qr_view`。字段包含 `page_path`、`event_name`、`placement`、`service_type`。
