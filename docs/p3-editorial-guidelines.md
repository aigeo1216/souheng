# P3 内容编辑规范

1. 先判断真实意图：一页只解决一个核心决策问题，并在开头直接回答。
2. 正文必须说明适用条件、实施边界和无法承诺的部分；禁止将 AI 提及、引用、排名、流量或询盘写成保证。
3. 事实性判断应给出可追溯的公开来源，并记录 `accessedAt`；国内平台规则没有可靠公开依据时标记为待核实，不以国际规则替代。
4. 结构化数据只能描述可见正文：不写虚构评价、评分、认证、客户、案例、价格或身份。
5. 作者使用组织编辑部，不创建虚构个人身份；发布日期和修改日期必须是真实编辑日期。
6. 发布前设置唯一 Title、Description、H1、Canonical、Breadcrumb、相关内链和图片 Alt；正文必须在静态 HTML 中可读。
7. `draft` 与 `review` 保持不可索引、不可推荐；发布后才允许加入集合页和 Sitemap。
8. 无授权的第三方图片、商标、截图和长篇正文不可进入正式资源目录。需要视觉资产时使用自制、授权或纯 CSS 替代。
