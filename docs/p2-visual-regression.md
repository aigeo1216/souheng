# P2 视觉回归

## 执行范围

- 视口：桌面 1440×900、移动 390×844。
- 页面：9 套模板，每套生成首屏和全页截图，共 36 张。
- 自动检查：水平溢出、Header/Footer、唯一 H1、核心模块、控制台异常、移动菜单。
- 输出：`output/p2-visual/{desktop-1440,mobile-390}/`（本地研究产物，Git 已忽略）。

## 与 P0/P1 基线对照

| 模板 | 接近基线的结构 | 主要差异 |
|---|---|---|
| 首页 | 60px Header、450/360 Hero、模块顺序、移动服务 2 列 | 使用原创渐变抽象图，无竞品轮播素材 |
| 服务列表 | 1170px 容器、桌面 3 列、移动单列、胶囊分类 | 卡片图为固定比例品牌占位 |
| 服务详情 | 首屏图文双栏、正文 8:4、移动单列 | 规格内容为 Fixture，无报价或承诺 |
| 资讯列表 | 桌面主栏+侧栏、移动单列、日期信息密度 | 原创摘要较短，页面长度更短 |
| 文章详情 | 居中标题、元信息、正文+推荐、上下篇 | 不复用原文和原图，正文长度按测试需要缩短 |
| 案例列表 | 桌面 4 列、深色标题覆盖、移动单列 | 卡片明确标注 DEMO，无真实客户素材 |
| 案例详情 | 自有 Banner、概览、长文结构 | 不复用促销图；无虚构结果、引语或证据 |
| 关于我们 | 标题留白、二级导航、宽正文 | 品牌图和主体资料为占位说明 |
| 咨询入口 | 联系方式+表单双区、移动单列 | 无公开留言；表单因无端点而禁用 |

整体比例、栅格、信息密度和移动折叠方式已接近参考基线；差异主要来自版权与事实边界，而非模板缺失。未设置无依据的像素相似度阈值。

## P3 调整项

- 接入自有图片后复核裁切比例、首屏对比度和图片 Alt。
- 真实内容长度进入后复核详情页节奏、相关推荐数量和 Footer 起始位置。
- 正式路由建立后启用基于当前路由的导航激活态。
